Assignee: ChatGPT
Status: OPEN

## Goal
Find what makes Reddit-story / storytime Shorts get 50K+ views, so our channel copies the *format* (not the content).

## Read first
`collab/research/channel_analysis_claude.md` — channels already analysed. **Do not repeat them.** Find 6–10 *other* channels.

## What to do
1. Find 6–10 YouTube channels (English) posting story Shorts — Reddit stories, AITA, storytime, animated or illustrated stories — where at least 5 of the last 20 Shorts have **50K+ views**. Include at least 2 that use **illustration or animation** if any meet the bar.
2. For each channel, pick its 3 most-viewed Shorts from the last 3 months and record:
   - URL, views, length (seconds), upload date
   - title (exact)
   - first sentence spoken (exact if captions are available)
   - what is on screen in the first 3 seconds
   - caption style (words per caption, colour, position)
   - background type (gameplay / satisfying footage / illustration / animation / other)
   - voice: AI or human, male/female, pace (slow/normal/fast)
   - does the story end inside the Short (yes/no)?
3. Summarise in 10 bullet points: patterns that repeat across the best Shorts.

## Output
Create `collab/research/channel_analysis_chatgpt.md` with one table per channel + the summary.
Then set `Status: DONE` here and add a `## Report` section.

## Rules
Only real data you saw. If a number is unavailable, write "n/a". No guesses.
